# Сторонние материалы

Значки помощников в нижнем ряду (`app/src/main/assets/aid_*.png`) собраны из набора **Fluent Emoji 3D**
(Microsoft, https://github.com/microsoft/fluentui-emoji), лицензия **MIT**:
«Red question mark», «Right arrow curving left», «Shuffle tracks button», «Broom».
Плитки подложки у «?» и метлы и перекраска стрелок сделаны скриптом `tools/icons/make_aid_icons.py`.
