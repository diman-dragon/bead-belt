# Общий ключ разработки

`dev.keystore` — **публичный** ключ, лежит в репозитории намеренно.

| | |
|---|---|
| Файл | `signing/dev.keystore` (PKCS12) |
| Пароль хранилища / ключа | `beadbelt` |
| Алиас | `beadbelt` |
| Срок | 100 лет |

Зачем: все сборки (локальные, из GitHub Actions, debug и release) подписаны одним и тем же ключом, поэтому новый APK встаёт поверх старого без удаления приложения и без ошибки «конфликт подписей». Чтобы установка прошла как обновление, `versionCode` должен быть не меньше установленного: он растёт вместе с версией (`npm run bump`).

**Только для разработки.** Для публикации в Google Play нужен отдельный закрытый ключ загрузки (см. `docs/PLAY_LATER.md`), этот использовать нельзя: любой, кто видит репозиторий, может подписать им свою сборку.
