# Bead Belt (Kotlin)

Нативная Android-игра в духе Marble Sort: нажимаешь на лотки сверху, шарики падают на вечный конвейер и уезжают в коробки своего цвета (по 3 шарика). Конвейер забит и нет подходящих коробок — проигрыш.

Чистый Kotlin, один `Activity`, рисование на `Canvas`, **без сторонних библиотек**. Уровни генерируются по номеру и проверяются решателем.

## Механики

- **Тап по лотку**: шарики по одному выпадают в воронку и скатываются по физике (круги с гравитацией и столкновениями) к воротам над конвейером.
- **Конвейер** вечно крутится; шарик, проезжая мимо коробки своего цвета, залетает в неё. В коробке 3 места; заполненная лопается, на её место выезжает следующая из очереди.
- **Проигрыш**: конвейер забит, и ни один шарик не подходит ни к одной коробке.
- **Стрелки** (с уровня 8): тап по лотку со стрелкой запускает и передние лотки соседних колонок в сторону стрелки.
- **Лифт** (каждый третий уровень с 15-го): коробка на лифте закрыта замком, пока не соберётся любая другая.
- **Ракета**: мгновенно закрывает самую выгодную коробку, убирая нужные шарики с поля.
- **Вернуть шарики**: до 8 шариков с ленты возвращаются новыми лотками в самую короткую колонку.
- **Монеты**: награда за уровень; ракета стоит 60, возврат 40 (в начале по 2 бесплатных).
- **100 уровней** с прокручиваемым списком; прогресс сохраняется.
- **Пауза** при сворачивании: игра ждёт нажатия «Продолжить».

Стрелки и лифт сделаны по описаниям обновлений Marble Sort в App Store; точные правила оригинала могли быть иными.

## Структура

| Файл | Что делает |

| `Painter.kt` | примитивы рисования: текст, кнопки, значки, фон с боке |
| `GameRenderer.kt` | отрисовка игрового поля и HUD |
| `Screens.kt` | меню, список уровней (с прокруткой), итоговая карточка, пауза |
| `Ui.kt` | раскладка и идентификаторы нажатий (одна и та же для рисования и ввода) |
| `GameView.kt` | цикл кадров, ввод, переходы между экранами |
| `Progress.kt` | сохранения: уровни, монеты, бустеры, звук |
| `Sound.kt` | звуки: синтез в WAV один раз + `SoundPool` |
| `Theme.kt` | палитра и шрифты |
| `MainActivity.kt` | полноэкранный режим, «Назад», пауза/возобновление |

## Скорость и физика

- Скорость ленты — `Game.SPEED` (сейчас 400, исходно было 110). Окно подбора шарика растёт со скоростью кадра, так что быстрая лента не «перепрыгивает» коробки.
- На ленте нарисованы гнёзда по числу мест (`Assets.pocket`): видно, какие места пустые. Решатель дискретный и от скорости не зависит, так что менять можно свободно.
- Шарики отскакивают по-настоящему при сильном ударе и спокойно ложатся кучей при слабом; из лотка высыпаются веером.
- Сильный удар даёт блик и звонкий «цок» (громче и выше при большей силе).

## Производительность

Режим «максимум плавности»: упрощённый фон (статичный), без слоя бликов и теней, запекание в разрешении до 2×, стопки лотков в 2 уровня, сглаженный шаг времени и сглаженные позиции шариков, фоновые потоки с низким приоритетом.

Замер заливки за кадр на экране 1080×2340 (исходно → сейчас): 16 МП → 6 МП, полноэкранных шейдерных заливок 3 → 0, `Path` за кадр 43 → 0.

- Фон (градиент, свет, боке, виньетка) запечён в один битмап; живыми остались три небольших пятна света.
- Все значки, шевроны ленты, стрелки лотков, блики и заголовок меню запечены в спрайты: Path-ы, пересоздаваемые каждый кадр, GPU не кэширует.
- Ящики, шарики, воронка и лента тоже битмапы; в кадре только `drawBitmap`.
- Физика: равные подшаги на кадр (число шагов не прыгает 1-2-1-2 на 90/120 Гц), поиск пар через сетку.
- Без тряски экрана и «дыхания» лотков (на мелких сдвигах битмапов они выглядят как дрожь). Тряска осталась только при поражении.
- В кадре нет аллокаций: кисти, шейдеры, строки и частицы переиспользуются, циклы без итераторов.
- Уровень, которого нет в кэше, генерируется в фоне, а не на UI-потоке.
- Звук через `SoundPool`; цикл кадров останавливается, когда приложение в фоне.

## Разработка в VS Code

1. Установите JDK 17, Android SDK (платформа 35) и Gradle 8.10+; переменная `ANDROID_HOME` должна указывать на SDK.
2. Откройте папку в VS Code, согласитесь на рекомендованные расширения.
3. `Terminal → Run Task`: **Тесты**, **Собрать debug APK**, **Установить на телефон (adb)**.
4. По желанию один раз выполните задачу «Создать Gradle Wrapper» и коммитьте `gradlew` и `gradle/wrapper/`.

Без локальной установки можно просто пушить: сборку делает GitHub Actions.

## GitHub Actions

`.github/workflows/android.yml` на каждый push / PR / ручной запуск: тесты → debug и release APK → артефакт `bead-belt-<версия>` в запуске. Ничего никуда не публикуется.

## Скриншоты

`docs/screens/`: меню, список уровней, игра, победа.

## Подпись и версии

Все сборки подписаны публичным ключом `signing/dev.keystore` (см. `signing/README.md`), `applicationId` прежний (`dev.beadbelt.game`): новая версия ставится поверх старой. Версия `X.Y.Z` в `gradle.properties`, `versionCode = X*100 + Y*10 + Z`; поднять: `python3 scripts/bump.py`.

## Уровни

Номер уровня (1–100) задаёт всё: число цветов растёт (3 → 8), коробок на цвет 2 → 4, запас конвейера сжимается, появляются стрелки и лифт. Генератор подбирает минимальную вместимость конвейера, при которой уровень проходим (бот-решатель), и добавляет запас. Тест `LevelsTest` проверяет все 100 уровней, появление механик, физику воронки и бустеры.
